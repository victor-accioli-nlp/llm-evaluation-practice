# LLM Evaluation Practice

## Overview
This repository contains practical exercises focused on **LLM (Large Language Model) Evaluation**.

LLM evaluation is the process of assessing model outputs based on:
- Accuracy
- Safety
- Clarity
- Helpfulness
- Reasoning quality

---

## Purpose
The goal of this project is to simulate real-world evaluation tasks used by AI companies.

Through this repository, I am practicing:
- Comparing AI responses
- Identifying hallucinations
- Evaluating safety risks
- Writing structured evaluation reports
